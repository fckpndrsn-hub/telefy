# Поиск и любимые альбомы

Поиск: Все / Треки / Артисты / Альбомы. Альбомы и EP берутся из SoundCloud по явным признакам типа релиза. Обычные пользовательские плейлисты не выводятся как альбомы. Две отдельно утверждённые ссылки включены редакционно: https://soundcloud.com/members-only-forever/sets/12-ep и https://soundcloud.com/pharaohdd/sets/red-um-dullboy-ep . Используются их исходные записи.

При совпадении запроса с названием релиза, артистом или ключами треков записи этих двух альбомов добавляются к выдаче треков. Порядок треков внутри альбома сохраняется из источника. Недоступные записи пропускаются без подстановки других треков.

Любимое — отдельный экран с поиском и вкладками «Треки» / «Альбомы». У треков стандартные строки с сердечками. У альбомов отдельные карточки с обложкой, названием, исполнителем и годом, если год указан источником. Если обложка не загрузилась, показывается музыкальная заглушка.

В модалке SoundCloud-альбома рядом со «Слушать» есть кнопка сохранения. Сердечко становится красным. Альбомы сохраняются в albums существующей библиотеки PostgreSQL; используются прежние авторизация и проверка версии. Старые клиенты, не присылающие albums, не стирают альбомы. Платные ограничения просмотра библиотеки сохранены.

Установка: заменить файлы выбранного архива в существующем репозитории. Новые переменные не нужны. Локально проверены классификация альбомов, привязка двух URL, порядок воспроизведения, сохранение/удаление, изоляция аккаунтов, конфликт версий и совместимость библиотеки. Живую выдачу SoundCloud и обложки нужно проверить после деплоя; живые API-ключи локально не использовались.


Стартовый экран теперь ограничен редакционным списком из 16 узнаваемых релизов. Для каждой позиции выбирается одна версия с доступными треками; пустые/недоступные источники не показываются ради заполнения количества. Подбор загружается последовательно небольшими порциями и кэшируется. Это не проверенный рейтинг популярности SoundCloud. Поиск остальных релизов и пагинация дискографии артиста сохранены.

Артисты представлены каноническими именами каталога и алиасами, а не списком аккаунтов /users. У каждого исполнителя один ID. Похожие названия фан-аккаунтов не создают новых карточек. Альбомы объединяются по исполнителю и очищенному названию, а не только по SoundCloud ID. В поиске альбомы — строки с плашкой «Альбом», без лайка; в любимом — карточки. У модалки одна общая прокрутка, кнопка «Назад», имя исполнителя открывает карточку артиста.
